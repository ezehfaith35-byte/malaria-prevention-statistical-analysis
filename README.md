Malaria Prevention Programme – Statistical Analysis

Project Overview

A statistical analysis of malaria prevention programme data from 600 households across three Local Government Areas (LGAs), aimed at providing evidence to support public health policy decisions.

Tools Used

- Python
- Google Colab
- Pandas, NumPy and SciPy

Key Analysis

- Data cleaning and quality checks
- Descriptive statistics
- Outlier detection using IQR
- Probability distributions
- Hypothesis testing
- Chi-square and t-tests
- Confidence interval estimation

Key Findings

- Overall bed-net usage was 55.5%, below the 80% target.
- LGA C recorded the lowest bed-net usage at 47%.
- Programme participants reported higher bed-net usage than non-participants.
- Haemoglobin levels were slightly higher among programme participants, although the effect size was small.

Recommendation

Strengthen the existing programme, prioritising areas with lower bed-net usage, before considering statewide expansion.
